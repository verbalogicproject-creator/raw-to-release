# Contributing

Keep `method/` provider-neutral and put native routes or model candidates only
in bindings. Change canonical method files first, then run
`python scripts/sync_method.py`. Add positive and targeted negative fixtures for
contract changes and behavioral tests for lifecycle changes.

Before proposing a change, run every command in the README development block.
Do not include transcripts, credentials, private source bodies, personal paths,
or fabricated empirical observations. Releases additionally require fresh CLI
journeys, cross-platform CI receipts, and the official plugin validator.
