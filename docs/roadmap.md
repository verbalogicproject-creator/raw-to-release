# Roadmap

1. **v0.1 — fixed idea-to-verified-branch lifecycle.** Supplies real artifacts
   and measured native behavior required by every later phase.
2. **v0.2 — general workflow language.** Adds validated conditional, skip,
   abort, checkpoint, bounded cycle-back, and compound AND/OR grammar. It waits
   for v0.1 evidence so grammar reflects actual workflows.
3. **v0.3 — production capability packs.** Adds API, schema, frontend/editor,
   Git-hosting, audit/fixer, packaging, and adversarial-review specialists after
   execution semantics stabilize.
4. **v0.4 — routing economics and trust.** Promotes heuristics only after
   recurrence across sanitized observations and reports costs only when visible.
5. **1.0 — ecosystem.** Verifies additional surfaces, publishes a binding kit,
   completes security/accessibility review, stabilizes contracts, and prepares
   universal-directory submission.

Name, trademark, repository, domain, and plugin-directory clearance are blocking
human publication checks. No substitute name is invented automatically.
